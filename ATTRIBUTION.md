# Attribution Ledger

Every third-party asset, icon, font and code lineage in **DrawCraft** is recorded here. DrawCraft is licensed `MIT OR Apache-2.0`; only original work and assets under the allowlist in [`deny.toml`](deny.toml) are accepted. Copyleft (`GPL`, `LGPL`, `AGPL`) code is never copied, ported or linked.

## Code lineage

| Upstream | License | What was taken | Where |
|---|---|---|---|
| **PaperCraft** (`alyxhard/papercraft`), commit `02e3453f2e33f4059384a71d782b4726270ed42d` | `MIT OR Apache-2.0` | Source of the `L0-L5` crates (`geom`, `color`, `raster`, `tablet`, `doc`, `ops`, `paint`, `compose`, `format`, `sync-protocol`, `sync`, `engine`), the headless CLI, the egui shell (`crates/ui`), the web host and the desktop shell, renamed to `drawcraft-*`; also `clippy.toml` and the shape of `deny.toml`. Its logo and Windows resource script were **not** taken. | `crates/*`, `apps/*` |
| **PaperCraft** `v0.1.2` to `v0.2.0` (public compare diff) | `MIT OR Apache-2.0` | Re-implemented: local profiles bound to the signed-in cloud account (`owner_cloud_user_id`, `accessible_local_profiles`) and the ruler improvements (variable depth, corner clamping, tick spacing, placement in the visible area). Not taken: sign-in modal rewrite, repository footer, updater. | `crates/sync`, `crates/engine/src/sync_state.rs`, `crates/ui/src/{canvas,toolbar,lib}.rs` |

Original DrawCraft work on top: study tapes and flashcards, tablet / palm-rejection modules, theme tokens and PDF dark-mode inversion, the `drawcraft-storage` crate, OPFS / IndexedDB persistence, the PWA shell, folders, favorites, import of notebook-app backups, Word and PDF files, custom page backgrounds, document-scan cleanup, and the redesigned library and editor.

Earlier file formats stay readable: `.scraft` / `.scraftpkg` (magics `SCFT` / `SCPK`), PaperCraft `.pcraft` / `.pcraftpkg` (`PCFT` / `PCPK`) and NoteCraft `.ncraft` / `.ncraftpkg` (`NCFT` / `NCPK`). DrawCraft writes `.dcraft` / `.dcraftpkg` (`DCFT` / `DCPK`).
